# Maquettes des écrans

Captures figées des maquettes générées avec Claude. Elles servent de référence visuelle (cahier des charges, section 6bis) : pour modifier un écran, on régénère la maquette, puis sa capture.

Formats : 1440 × 900 pour l'ordinateur, 1280 × 800 pour les écrans du bar sur tablette, 390 × 844 pour le téléphone.
